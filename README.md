# Blos

A marketing site for **Blos**, the platform for co-owning AI agents. The pages follow the public Olas site, with a new mark and the company name changed to Blos.

Emerald is the agent app store. The Cref Marketplace is the bazaar. BLOS is the utility token that coordinates staking, fees, and the flywheel.

This is a design recreation, not the Olas product. It is not affiliated with Valory or the Olas DAO. See [NOTICE](NOTICE) and [the disclaimer](http://127.0.0.1:4317/disclaimer).

## Run it

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4317](http://127.0.0.1:4317).

```bash
npm run build
npm start
```
